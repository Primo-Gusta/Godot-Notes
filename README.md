# Godot Notes 📝

A simple Godot 4.x plugin to keep notes inside your editor. Your notes are automatically saved within the project folder.

## 🚀 How to Install

1. **Download**: Click the green **Code** button and select **Download ZIP**.
2. **Extract**: Unzip the folder.
3. **Copy**: Move the `godot_notes` folder into your project's `res://addons/` directory.
   * *The final path should be:* `your_project/addons/godot_notes/plugin.cfg`
4. **Enable**: Open Godot, go to **Project Settings** > **Plugins**, and check the **Enable** box next to "Godot Notes".

## ✨ Features

* **Auto-save**: Saves instantly as you type.
* **Persistent**: Your text stays there even after restarting Godot.
* **Location**: Located in the **Bottom Panel** alongside Output and Debugger.
